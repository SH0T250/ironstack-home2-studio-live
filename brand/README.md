# Ironstack identity

Approved direction: IRONSTACK.PRO, metallic silver and electric blue on a navy blueprint grid, with the exact blue tagline **BUILD BETTER SYSTEMS.**

`ironstack-logo.png` is the project asset used by the dashboard shell, room viewer, floor viewer and existing branded print surfaces. It was created with the built-in image editor using Austin's two supplied screenshots, preserving the first image's visual direction and replacing its former tagline with the second image's wording. Prompt: preserve the metallic IRONSTACK and blue .PRO wordmark, navy blueprint frame, replace IDEAS / SYSTEMS / RESULTS with BUILD BETTER SYSTEMS. in matching blue, tight horizontal composition, no additional icon or copy.

The new lockup is raster, not an editable vector. Historical SVG concepts remain for reference but are not the active logo. The Home2 Suites mark identifies the project and stays separate from the Ironstack company logo; see its asset provenance file.
