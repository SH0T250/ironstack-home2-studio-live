# Ironstack Home2 Studio

**Live site: https://sh0t250.github.io/ironstack-home2-studio-live/**

A construction field platform for the Home2 Suites by Hilton project in
Eagle Pass, TX (115 keys), built by Ironstack. The full first floor and every
guest room type are modeled in 3D in the browser, wired to room-by-room FF&E
checklists, the drawing set, and field photos. No install, no plugins; it runs
on a phone or a desktop.

## What's inside

- **Floor 1 in 3D** - overview, exploded study, exterior with site work, and a
  first-person corridor walk. Every space is tinted by checklist progress.
- **Guest room models** - King Studio and Queen/Queen families with
  photo-informed finishes, tagged FF&E, dimension callouts, layer toggles,
  item search and isolate.
- **Checklists** - 1,764 line items across 51 first-floor spaces, linked both
  ways with the model: pick an object to see its checklist line, pick a line
  to fly to the object.
- **Documents** - zoomable plan, elevation and detail views for each room,
  plus field photo review.

Progress figures on the public site are a saved review snapshot, not the live
crew record. Furniture placement and finishes are visual approximations; the
source drawings control.

This is a static deployment of the Ironstack Home2 Studio build. The two 3D
viewer pages carry a leading doctype added at deploy time; everything else is
byte-for-byte the studio build.
